# AI Reflection
## Tools
I used ChatGPT to help me understand the lottery assignment, review my C++ code, check my expected test results, and format the tables in my README.md file so they would display correctly on GitHub.

## One Decision
One important decision was using a loop to compare the winning digits and player digits at the same positions. ChatGPT explained why comparing the same indexes was important because a matching digit in another position should not count. I kept this approach because it followed the assignment requirements.

## Specific Check
I tested the program using fixed winning digits and different player inputs. For example, when the winning digits were [7, 4, 9, 1, 3] and the player digits were [4, 2, 9, 7, 3], the expected result was 2 matches. I also tested the random generation and checked that the expected and actual match counts were the same.

## Learning
I learned how to create arrays, use loops to generate and collect digits, and compare values at matching positions. I can now better understand how to count matching positions using an if statement and a counter. I still need to practice tracing loops and working with random number generation in C++.
